What kind of app is it?

Minesweeper asks you to clear safe cells while leaving the mines covered. A revealed number tells you how many mines touch that cell, including diagonally. Use overlapping clues to identify safe moves and place flags where you believe mines are located. The rules are compact, but careful deductions can connect information from several parts of a board.

The public iPhone and iPad listing for Minesweeper·· describes classic play, flags, Easy, Medium and Hard difficulties, offline play and automatic progress saving so you can continue a game later. Its release notes also mention an Expert difficulty. The verified public listing is version 2.1; the page describes that released app rather than promising features from another version.

People choosing a Minesweeper game may care about more than completion time. Board difficulty, input comfort, a no-guess mode and metrics such as 3BV or efficiency can affect what makes a good fit. These are useful comparison criteria, but they are not all verified features of this public release.

Before you download.

Does this Minesweeper show 3BV, 3BV/s or efficiency?

Those metrics are not documented or verified in the current public version 2.1 listing. Do not choose this release on the assumption that it includes an advanced statistics dashboard.

Is there a verified no-guess mode?

A no-guess mode is not documented or verified in the current public listing. We do not promise that every generated board can be completed without guessing.

Can I play offline and resume later?

The public iOS description advertises offline gameplay and automatic progress saving. This does not establish an ad-free experience, cloud synchronization or an absence of network activity when connected.
