The one rule every technique builds on

Every row, every column and every 3 × 3 box must contain the digits 1 to 9 exactly once. Each technique below is a way of using that rule to prove where a digit must go, or where it cannot go. You never need to guess in a well-made Sudoku.

Many techniques rely on candidates, also called pencil marks: the small digits that could still fit in an empty cell. In our Sudoku app, candidates can fill in automatically; if you prefer to note them yourself, turn off Autofill Pencil in Settings.

1. Last digit

When a row, column or box already holds eight digits, the ninth is whichever digit is missing. It is the simplest technique, and the first to look for on any new puzzle.

2. Naked single

A naked single is a cell with only one candidate left. Check the digits already placed in the cell’s row, column and box. If eight of the nine digits appear there, the remaining digit is the answer for that cell.

3. Hidden single

A hidden single is a digit that can go in only one cell of a row, column or box, even though that cell may still have other candidates. Pick a digit, say 8, and scan one box: if every other empty cell in the box already sees an 8 in its row or column, the 8 must go in the one cell that remains.

Scanning digit by digit, 1 through 9, across every box is the fastest way to solve easy and medium puzzles.

4. Naked pair

When two cells in the same row, column or box contain exactly the same two candidates, for example 7 and 8, those two digits must occupy those two cells. You can remove 7 and 8 from the candidates of every other cell in that row, column or box.

5. Hidden pair

A hidden pair is the reverse of a naked pair. If two digits, for example 3 and 4, appear as candidates in only the same two cells of a row, column or box, those cells must hold 3 and 4. Remove every other candidate from those two cells.

6. Locked candidates

Locked candidates work across a box and a line, and come in two forms.

  • Pointing: inside one box, a digit’s candidates all sit in a single row or column. The digit must be placed in that box, so remove it from the rest of that row or column outside the box.
  • Claiming: inside one row or column, a digit’s candidates all sit within a single box. Remove that digit from the other cells of the box.

7. Triples and larger groups

Pairs extend to groups. If three cells in a unit hold only candidates drawn from the same three digits, a naked triple, those digits can be removed from the rest of the unit. If three digits appear only within the same three cells, a hidden triple, other candidates can be removed from those cells.

A solving routine that works

  1. Fill every last digit.
  2. Scan for hidden singles, digit by digit.
  3. Look for naked singles in the most crowded rows, columns and boxes.
  4. When singles run out, review the candidates and look for pairs.
  5. Apply locked candidates, then return to step 2: each elimination often reveals new singles.

Stuck? Recheck your candidates first. A single wrong pencil mark is the most common reason a puzzle seems impossible. In our Sudoku app, incorrect numbers show in red; turn on Manually Checking Mistakes in Settings if you would rather check your own work.
